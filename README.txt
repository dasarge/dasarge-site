DASARGE.COM WEBSITE PACKAGE
===========================

Files included:
- index.html
- Donald_Sargent_Resume.pdf
- Manufacturing_Systems_Automation_Highlights.pdf

Purpose:
This is a static one-page professional site for dasarge.com.

How to deploy:
1. Unzip this package.
2. Upload all files to the public web root of your hosting account.
   Common folder names:
   - public_html
   - www
   - htdocs
   - site root
3. Make sure index.html is in the root folder.
4. Visit https://dasarge.com and verify:
   - page loads
   - resume link works
   - project summary link works
   - email link opens correctly

If using Netlify:
1. Go to Netlify.
2. Drag the unzipped folder into the deploy area.
3. Add custom domain: dasarge.com.
4. Follow Netlify DNS instructions.

If using Cloudflare Pages:
1. Create a Pages project.
2. Upload the folder or connect a GitHub repository.
3. Add custom domain: dasarge.com.

Notes:
- No server code is required.
- No database is required.
- This is safe to host on any basic static hosting service.
